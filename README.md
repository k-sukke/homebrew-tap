# homebrew-tap

Homebrew tap for [k-sukke](https://github.com/k-sukke) tools. Formulae are published automatically by [cargo-dist](https://axodotdev.github.io/cargo-dist/).

## Install

```sh
brew install k-sukke/tap/zem
```

## Packages

| Formula | Project |
|---------|---------|
| `zem` | [k-sukke/zem](https://github.com/k-sukke/zem) — Zephyr Environment Manager |
